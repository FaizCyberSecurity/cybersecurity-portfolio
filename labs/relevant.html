TryHackMe: Relevant Walkthrough

Platform: TryHackMe | Category: Windows Web / SMB Exploitation

SMB IIS PrivEsc

// 01. Nmap Scan

Ran comprehensive scan targeting all TCP ports:

nmap -sC -sV -p- -oA nmap/relevant <TARGET_IP>

Open ports: 80 (HTTP), 135 (RPC), 139/445 (SMB), 3389 (RDP), 49663 (IIS HTTP).

// 02. SMB Enumeration

Enumerate accessible shares anonymously:

smbclient -L //<TARGET_IP>/ -N

Identified writeable share nt4wrksv. Verified that file uploads to this share are accessible over IIS on port 49663.

// 03. Initial Access & Root

  • Generated ASPX web shell using msfvenom and uploaded it via SMB client.
  • Triggered shell via web browser to establish reverse connection as iis apppool\defaultapppool.
  • Checked privileges via whoami /priv and identified SeImpersonatePrivilege enabled.
  • Executed PrintSpoofer / Potato exploit to gain NT AUTHORITY\SYSTEM shell.
