Platform: TryHackMe | Category: Web / Linux Privilege Escalation

WordPress Linux SUID

// Key 1: Web Recon

Inspected robots.txt file to find the first key and custom dictionary file:

curl http://<TARGET_IP>/robots.txt

// Key 2: WordPress Exploitation

  • Cleaned wordlist to remove duplicates using sort -u.
  • Enumerated valid usernames via login error message behavior (found Elliot).
  • Brute-forced password using Hydra / WPScan to access /wp-login.php.
  • Uploaded PHP reverse shell via Editor tool in WordPress dashboard.
  • Cracked raw MD5 hash found in user directory to gain access to user robot.

// Key 3: Root Privilege Escalation

Searched for SUID binaries on system:

find / -perm -u=s -type f 2>/dev/null

Discovered SUID bit set on nmap (v2.02). Utilized interactive mode execution (nmap --interactive) to spawn a root shell.
