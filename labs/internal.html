TryHackMe: Internal Walkthrough

Platform: TryHackMe | Category: Active Directory / Network Pentesting

Active Directory Windows PrivEsc

// 01. Reconnaissance

Initial network enumeration using Nmap to discover open ports and services:

nmap -sC -sV -oA nmap/internal <TARGET_IP>

Discovered services include SMB (139/445), HTTP (80), and NetBIOS.

// 02. Enumeration

Directory brute-forcing using Gobuster to reveal hidden endpoints:

gobuster dir -u http://<TARGET_IP>/ -w /usr/share/wordlists/dirb/common.txt

Found WordPress blog installation hosted under /blog.

// 03. Exploitation & Privilege Escalation

  • Brute-forced WordPress credentials using WPScan.
  • Uploaded a PHP reverse shell via theme editor to gain initial foot hold (`www-data`).
  • Discovered internal Jenkins instance running on port 8080 via local enumeration.
  • Pivoted through SSH tunnel to access Jenkins, recovered administrative credentials, and escalated privileges to Root.
