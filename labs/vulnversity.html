gobuster dir -u http://<TARGET_IP>:31337/ -w /usr/share/wordlists/dirb/common.txt

// 02. File Upload Bypass

// 03. Privilege Escalation

Identified misconfigured SUID permission on system utility systemctl:

find / -user root -perm -4000 -exec ls -ldb {} \; 2>/dev/null

Created a custom systemd service file to execute a root reverse shell payload or write flag output to elevated directory.
