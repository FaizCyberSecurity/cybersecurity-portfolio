🔍 1. Enumeration [Nmap Scan]

Nmap Scan

nmap -F -sV -v <IP> -p 3333

Open Ports Identified

  • 21 (FTP)
  • 22 (SSH)
  • 139 (SMB)
  • 445 (SMB)
  • 3128 (Proxy)
  • 3333 (HTTP)

Key Finding

Web server running on port 3333.

🌐 2. Directory Brute Forcing & Exploitation [Gobuster & Bypass]

Tool Used

Gobuster

Discovered Directories

  • /css
  • /fonts
  • /images
  • /internal
  • /js

Target

/internal/ → File upload functionality identified.

⚡ Bypassing Upload Restrictions

The standard .php extension was blocked. Tested alternatives:

  • .php3
  • .php4
  • .php5
  • .phtml ✅

Exploitation

  • Uploaded reverse shell using the .phtml extension.
  • Successfully gained shell access.
🔐 3. Privilege Escalation [SUID & GTFOBins]

Finding SUID Binaries

find / -user root -perm -4000 -exec ls -ldb {} \; 2>/dev/null

Vulnerable Binary

/bin/systemctl

Exploitation Method

  • Referenced GTFOBins for systemctl escalation techniques.
  • Used systemctl to escalate privileges to root.
🏁 Final Result: Root shell obtained & retrieved root.txt. Lab successfully completed!
